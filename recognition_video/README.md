# Модуль розпізнавання відео

## Опис
Модуль `recognition_video` відповідає за обробку та аналіз відеофайлів у межах мультимодальної системи розпізнавання даних.  
Застосунок дозволяє завантажувати відео, виконувати базову обробку кадрів та зберігати результати аналізу для подальшого перегляду.

---

## Підтримувані формати
- MP4  
- AVI  
- MOV  
- MKV  

---

## Основний workflow
1. Користувач завантажує відеофайл через веб‑інтерфейс  
2. Файл зберігається у директорії `media/`  
3. Модуль виконує аналіз відео (наприклад, вибір ключових кадрів або базову обробку)  
4. Результат зберігається у базі даних  
5. Користувач переглядає результат у detail‑view  

---

## Основні компоненти

### Модель
Зберігає:
- завантажений відеофайл  
- статус обробки  
- результати аналізу (наприклад, шлях до збережених кадрів або метадані)  

### Upload View
Обробляє завантаження відео та ініціює процес аналізу.

### Video Analysis Utility
Виконує обробку відео, зокрема:
- зчитування відеопотоку  
- вибір ключових кадрів  
- конвертацію кадрів у зображення  
- отримання базових характеристик (роздільність, FPS, тривалість)  

### Detail View
Відображає результати аналізу користувачу.

---

## Результат роботи
- ключові кадри відео  
- базові характеристики відео (тривалість, FPS, розмір кадру)  
- можливість подальшого аналізу або інтеграції з іншими модулями  

---

## Залежності
- `opencv-python`  
- `numpy`  
- `pillow` (для роботи з кадрами)  

---

## Місце в системі
Модуль є частиною мультимодальної системи розпізнавання, яка також включає:
- аудіо  
- зображення  
- спектральний аналіз  
- OCR  

Може використовуватися як окремо, так і разом з іншими модальностями.

---

## Примітки
- Обробка виконується синхронно  
- Модуль легко розширити додатковими алгоритмами комп’ютерного зору та відеоаналізу
