# Модуль оптичного розпізнавання тексту (OCR)

## Опис
Модуль `recognition_ocr` відповідає за оптичне розпізнавання тексту з растрових зображень та PDF‑документів.  
Застосунок дозволяє завантажувати файли, автоматично виконувати OCR‑обробку та зберігати результати у базі даних для подальшого перегляду.

---

## Підтримувані формати
Модуль працює з такими типами файлів:

- PNG  
- JPG / JPEG  
- PDF  

---

## Основний workflow
1. Користувач завантажує зображення або PDF через веб‑інтерфейс  
2. Файл зберігається у директорії `media/`  
3. Модуль виконує OCR‑аналіз за допомогою Tesseract  
4. Розпізнаний текст зберігається у базі даних  
5. Користувач переглядає результат у detail‑view  

---

## Основні компоненти

### Модель
Зберігає:
- завантажений файл  
- статус обробки  
- розпізнаний текст  
- час створення запису  

### Upload View
Обробляє завантаження файлу та запускає OCR‑аналіз.

### OCR Utility
Виконує:
- зчитування зображення або PDF  
- попередню обробку (конвертація, нормалізація)  
- розпізнавання тексту через Tesseract  
- повернення чистого текстового результату  

### Detail View
Відображає:
- завантажений файл  
- розпізнаний текст  
- метадані  

---

## Результат роботи
- текст, розпізнаний з PDF або зображення  
- можливість копіювання, подальшої обробки або інтеграції з іншими модулями  

---

## Залежності
- `pytesseract`  
- `Pillow`  
- `pdf2image` (для конвертації PDF у зображення)  

---

## Місце в системі
Модуль є частиною мультимодальної системи розпізнавання, яка також включає:
- аудіо  
- відео  
- зображення  
- спектральний аналіз  

---

## Примітки
- OCR виконується синхронно  
- Tesseract має бути встановлений у системі  
- Модуль підтримує як зображення, так і PDF‑документи
