# Модуль спектрального аналізу

## Опис
Модуль `recognition_spectrum` виконує спектральний аналіз аудіосигналів у межах мультимодальної системи розпізнавання даних.  
Застосунок приймає аудіофайли, обчислює їх спектральні характеристики та автоматично будує мел‑спектрограму, яку зберігає у вигляді PNG‑зображення.

---

## Підтримувані формати
Модуль працює виключно з аудіофайлами:

- WAV  
- MP3  
- FLAC  

---

## Основний workflow
1. Користувач завантажує аудіофайл через веб‑інтерфейс  
2. Файл зберігається у директорії `media/`  
3. Модуль виконує два типи аналізу:
   - спектральний аналіз через FFT  
   - побудову мел‑спектрограми  
4. Згенерована спектрограма зберігається у `media/spectrograms/`  
5. Числові характеристики та шлях до PNG зберігаються у базі даних  
6. Користувач переглядає результат у detail‑view  

---

## Основні компоненти

### Модель
Зберігає:
- завантажений аудіофайл  
- шлях до згенерованої спектрограми  
- домінантні частоти  
- максимальну та середню амплітуду  
- статус обробки  

### Upload View
Обробляє завантаження файлу та запускає спектральний аналіз.

### Функція `analyze_spectrum(path)`
Виконує:
- завантаження сигналу  
- обчислення FFT  
- визначення 5 домінантних частот  
- обчислення:
  - максимальної амплітуди  
  - середньої амплітуди  

### Функція `save_spectrogram(path)`
Виконує:
- побудову мел‑спектрограми  
- логарифмічне перетворення (dB)  
- збереження PNG з унікальним ім’ям  
- повернення шляху до зображення  

### Detail View
Відображає:
- спектрограму  
- домінантні частоти  
- числові характеристики сигналу  

---

## Результат роботи
- PNG‑зображення мел‑спектрограми  
- список домінантних частот  
- максимальна та середня амплітуда сигналу

- аудіо
